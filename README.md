# One Letter: Coffee or Tea

One letter choosing coffee over tea, written for the [Make.fun bounty](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

`main.py` writes the letter to `/output/entry.txt`:

> A

A for coffee — the day starts when the caffeine does. Tea is calm; coffee is alive.

Run it with `python3 main.py`.
